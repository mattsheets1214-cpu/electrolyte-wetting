# Instructions for Claude Code

Read `AI_CONTEXT.md` before making any change. It defines the architecture, the scientific conventions and the honesty rules for this project.

Always: work on a branch, keep physics in `src/physics/` (SI units), run `npm test`, `python -m pytest python/tests -q` and `npm run build`, update `CHANGELOG.md`, and open a pull request. Never push to `main` and never invent data, references, transcripts or AI evidence.
